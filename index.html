How to use the modules in your own LMS

Every module comes in two formats. The .h5p file is best for Moodle, WordPress and the Lumi editor, and lets you translate or adapt the content. The SCORM 1.2 package (.zip) works in almost any LMS, including Canvas, Blackboard, Brightspace, TalentLMS and Moodle, and reports completion and score to the gradebook.

  1. Download the module's .h5p file from this page.
  2. In your Moodle course, turn Edit mode on and click Add an activity or resource → H5P.
  3. Give the activity a name and drag the .h5p file into Package file.
  4. Under Grade, choose the maximum grade and grading method if you want quiz scores in the gradebook.
  5. Click Save and display. Learners now see the full interactive book inside your course.

Works in Moodle 3.9 and later, which include H5P out of the box. If the upload is refused because of its size, ask your Moodle administrator to raise the maximum upload size. If Moodle says a content type is missing, the administrator can allow it under Site administration → H5P → Manage H5P content types.

Download the module's SCORM package (the SCORM button on its card). Keep the .zip as it is: do not unzip it.

Moodle
  1. In your course, turn Edit mode on and click Add an activity or resource → SCORM package.
  2. Give it a name and drag the .zip into Package file.
  3. Under Appearance, set Display package to New window or Current window and the size to 100% wide.
  4. Under Grade, choose Highest grade. Under Activity completion, you can require status “completed” or a passing grade.
  5. Click Save and display.
Canvas
  1. In your course, go to Settings → Import Course Content.
  2. Choose Content Type: SCORM package, select the .zip and click Import.
  3. The module appears as a graded assignment. Publish it when you are ready.

If you don't see the SCORM option, ask your Canvas administrator to enable the SCORM app for your account.

Blackboard Learn
  1. Open a content area and choose Build Content → Content Package (SCORM). In Ultra courses, click + → Create → SCORM package.
  2. Browse to the .zip, click Submit, then give it a title.
  3. Turn on Grading if you want the score in the Grade Center, and click Submit.
Brightspace (D2L) and other platforms
  1. In Brightspace, open Content, choose a module and click Upload / Create → Add a SCORM Package, then upload the .zip.
  2. In other platforms (TalentLMS, Docebo, Totara, Sakai and similar), look for Add SCORM, Import package or Upload content and select the .zip.

The package reports completed when the learner has read every chapter, and a score (0–100) based on the knowledge-check questions. All media are inside the package, so it works without access to this website. Some packages are up to 80 MB: if the upload is refused, ask your LMS administrator to raise the maximum upload size.

  1. In WordPress, go to Plugins → Add New, search for “H5P”, then install and activate it.
  2. Open H5P Content → Add New, choose Upload, select the .h5p file and click Use.
  3. Click Create. WordPress shows a shortcode such as [h5p id="1"].
  4. Paste the shortcode into any page or post to show the module.

Large modules need a PHP upload limit (upload_max_filesize) bigger than the file. Your hosting provider can change it.

Canvas, Blackboard, Brightspace and most other platforms don't read .h5p files directly. Three ways to use the modules there:

  1. SCORM package (recommended): click SCORM on the module's card and upload the .zip to your LMS. See the SCORM tab for step-by-step instructions.
  2. H5P.com: if your institution subscribes to H5P.com, upload the file there and connect it to your LMS through LTI so scores reach the gradebook.
  3. Simple link or embed: link to the module's Start module address from this page, or embed it in an iframe. Learners can use it, but scores are not recorded.
  1. Install the free Lumi desktop app (Windows, macOS, Linux).
  2. Click Open and choose the downloaded .h5p file to use the module without an internet connection.
  3. To adapt or translate it, edit the text in Lumi and save, or export it again as .h5p, HTML or SCORM.

When you adapt a module, please keep its “Acknowledgements & Disclaimer” chapter and credit the original authors and the BriGRETE project.

Good to know

  • On this site, quiz answers are for self-assessment only and scores are not stored. Use the H5P file in your own LMS to record results.
  • Modules work best on a laptop or tablet, and they also run on phones.
