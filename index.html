How to use the H5P files in your own LMS

Every module can be downloaded as a standard .h5p file. H5P is an open format, so you can add the modules to your institution's learning platform, track learners' scores there, translate them or adapt them to your course.

  1. Download the module's .h5p file from this page.
  2. In your Moodle course, turn Edit mode on and click Add an activity or resource → H5P.
  3. Give the activity a name and drag the .h5p file into Package file.
  4. Under Grade, choose the maximum grade and grading method if you want quiz scores in the gradebook.
  5. Click Save and display. Learners now see the full interactive book inside your course.

Works in Moodle 3.9 and later, which include H5P out of the box. If the upload is refused because of its size, ask your Moodle administrator to raise the maximum upload size. If Moodle says a content type is missing, the administrator can allow it under Site administration → H5P → Manage H5P content types.

  1. In WordPress, go to Plugins → Add New, search for “H5P”, then install and activate it.
  2. Open H5P Content → Add New, choose Upload, select the .h5p file and click Use.
  3. Click Create. WordPress shows a shortcode such as [h5p id="1"].
  4. Paste the shortcode into any page or post to show the module.

Large modules need a PHP upload limit (upload_max_filesize) bigger than the file. Your hosting provider can change it.

Canvas, Blackboard, Brightspace and most other platforms don't read .h5p files directly. Three ways to use the modules there:

  1. SCORM package: open the .h5p in the free Lumi app and choose Export → SCORM. Upload the resulting SCORM package to your LMS like any other SCORM course.
  2. H5P.com: if your institution subscribes to H5P.com, upload the file there and connect it to your LMS through LTI so scores reach the gradebook.
  3. Simple link or embed: link to the module's Start module address from this page, or embed it in an iframe. Learners can use it, but scores are not recorded.
  1. Install the free Lumi desktop app (Windows, macOS, Linux).
  2. Click Open and choose the downloaded .h5p file to use the module without an internet connection.
  3. To adapt or translate it, edit the text in Lumi and save, or export it again as .h5p, HTML or SCORM.

When you adapt a module, please keep its “Acknowledgements & Disclaimer” chapter and credit the original authors and the BriGRETE project.

Good to know

  • On this site, quiz answers are for self-assessment only and scores are not stored. Use the H5P file in your own LMS to record results.
  • Modules work best on a laptop or tablet, and they also run on phones.
